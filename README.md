# COMP1511/1911 Tutorial Notes

Hi there!! This repo contains the notes that I use to teach COMP[1511](https://www.handbook.unsw.edu.au/undergraduate/courses/2027/COMP1511)/[1911](https://www.handbook.unsw.edu.au/undergraduate/courses/2027/COMP1911) tutorials.

I use [presenterm](https://mfontanini.github.io/presenterm/) for slides, so they are written in markdown.
Basically everything is written in markdown here.

The repo is divided into the 10 weeks (excluding week 6) that the course runs over.
- [Week 1 - Navigating the terminal and writing your first C program](week01)
- [Week 2 - Variables, constants, operators, and logic](week02)
- [Week 3 - Loops, structs, and enums](week03)
- [Week 4 - Arrays and functions](week04)
- [Week 5 - 2d arrays and strings](week05)
- [Week 7 - Pointers and command line arguments](week07)
- [Week 8 - Malloc and Linked lists](week08)
- [Week 9 - More linked lists and memory leaks](week09)
- [Week 10 - Practice problems for the final exam](week10)
